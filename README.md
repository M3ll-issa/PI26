# Kóiros

## Descrição
O Kóiros é um clube virtual criado para aproximar leitores, livros e diferentes formas de interpretar uma história. 

## Objetivo
Aproximar usuários da leitura, recompensando por livros lidos

## Tecnologias Utilizadas

### Frontend (1TW)
- HTML
- CSS
- Bootstrap

## Funcionalidades
- Descrição dos livros
- Calendário de eventos
- Recompensa de usuários com pódio por tempo de leitura
- Chat com outros membros

## Estrutura do Projeto
pasta css com arquivo style.css, pasta IMG com varias imagens e a pasta raiz com arquivos HTML.

## Como Executar
Abrir o arquivo index.html no seu navegador de preferência.
